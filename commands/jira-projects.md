description: List, view, and manage Jira projects
agent: build
---

Execute the following Jira projects command using the CLI tool:

```
node "$env:USERPROFILE\.config\gs-skills\lib\jira.js" $ARGUMENTS
```

If no arguments provided, run:
```
node "$env:USERPROFILE\.config\gs-skills\lib\jira.js" list-projects
```

Present the results clearly to the user.
