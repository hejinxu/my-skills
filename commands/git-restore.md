---
description: 还原工作区中未提交的更改
agent: build
---

对当前工作区执行 git restore 操作，还原未提交的更改。

参数：$ARGUMENTS

**请加载 git-restore skill 获取详细步骤。**

**⚠️ 重要：此操作不可逆！必须先展示将被还原的内容，并请求用户确认后再执行。**

根据参数执行：
- `all` 或无参数：还原所有未提交更改
- `<file>`：还原指定文件

**执行前必须：**
1. 执行 `git status` 展示将被还原的文件
2. 展示每个文件的更改摘要
3. 请求用户确认
4. 确认后才执行还原命令
