description: 将暂存区的更改提交到本地仓库
agent: build
---

对当前工作区执行 git commit 操作，将暂存区的更改提交到本地仓库。

参数：$ARGUMENTS

**请加载 git-commit skill 获取详细步骤。**

根据参数执行：
- `-m "<message>"`：直接提交
- `-a -m "<message>"`：自动暂存所有已跟踪文件并提交
- 无参数：引导用户输入提交信息
- `--amend`：修改最近一次提交

**提交前必须：**
1. 执行 `git status` 查看将提交的内容
2. 展示将提交的文件列表
3. 确认提交信息
4. 等待用户确认或输入信息后才执行提交
